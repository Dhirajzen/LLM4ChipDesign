Explanation:
A synthesizable Trojan was inserted into the LC controller module using extra logic to detect a token register write concurrent with an external asynchronous reset and, if so, force the LC state to the insecure TEST state for several cycles. All original functionality is maintained and unchanged unless the rare trigger occurs.

Trigger:
The Trojan is activated only if a transition_token register write coincides (within one clock cycle) with an asserted external system reset (sys_rst_ext_ni low); otherwise, normal operation is unaffected.
